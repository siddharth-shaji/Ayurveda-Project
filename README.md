**Ayurveda Health – Services Website**

A modern and visually appealing website designed to showcase health and wellness-related services. 
It features a navigation menu, an introductory section with a brief description of Ayurveda health, and a call-to-action button to explore more. 
The services section highlights four key offerings: Web Development, UI/UX Design, App Development, and DevOps. 
The website also includes a footer with the brand logo and social media links, providing a simple and organized browsing experience.
